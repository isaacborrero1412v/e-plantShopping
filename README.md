# Paradise Nursery Shopping Application

An interactive e-commerce web application for an online plant shop built with React and Redux Toolkit.

## Features
- Landing page with company background and "Get Started" navigation.
- Product listing categorized with 6 unique plants per category.
- Dynamic shopping cart management (add, remove, update quantities).
- Real-time cart total cost and dynamic badge count.

## Setup Instructions
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm start` to run the app locally.
